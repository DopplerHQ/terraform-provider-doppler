# doppler_project_member_user (Resource)

Manage a Doppler project user member.

**Note:** The `doppler_project_member_user` resource will clear/replace all existing roles the member holds on the project.
Combinations of `doppler_project_member_user` and `doppler_project_member_user_role_assignment` for the same member will produce inconsistent behavior.
To give a member several roles, use `doppler_project_member_user_role_assignment` only.

## Example Usage

```terraform
data "doppler_user" "brian" {
  email = "brian@doppler.com"
}

resource "doppler_project_member_user" "backend_brian" {
  project      = "backend"
  user_slug    = data.doppler_user.brian.slug
  role         = "collaborator"
  environments = ["dev", "stg"]
}
```
